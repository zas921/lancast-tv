# 轻投屏 TV 0.1.1 · 开源测试版

只在电视安装，手机通过支持标准 DLNA 的视频 App 发现电视并控制媒体播放。最低 Android 5.1（API 22）。本地照片、视频、音乐可通过手机浏览器发送，无需手机端 APK。

本次修复慢回调导致的播放状态丢失，增加通知拒收重试、回调 IP 固定、HTTP 边界校验和超时操作取消。补齐跨平台打包脚本、依赖锁文件、MIT 许可证、贡献说明与 CI。

本地验证：158 项普通协议检查、161 项含真实组播的协议检查、14 项浏览器界面检查；二维码与独立实现全部一致，APK 签名校验通过。

**兼容范围：** 尚未在大麦电视及具体商业视频 App 上实测。不包含 AirPlay / Miracast 镜像、Google Cast、乐播私有协议和 DRM 授权，不能保证所有主流视频 App 都能发现或播放。

此包使用开发签名，面向侧载测试。APK 与源码版本对应；SHA256SUMS.txt 用于核对文件完整性。请按 README 安装，并在 Issue 中反馈电视、手机和视频 App 的版本信息。
